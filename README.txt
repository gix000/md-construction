M.D CONSTRUCTION — WEBSITE FILES
==================================

UPLOAD BOTH TO YOUR GITHUB REPO:
  index.html          → your website
  admin/index.html    → your admin panel

YOUR URLS AFTER UPLOAD:
  md-construction.org          → website
  md-construction.org/admin    → admin panel

FIRST TIME SETUP:
1. Upload both files/folders to GitHub
2. Go to md-construction.org/admin
3. Login with password: MDadmin2024
4. Go to GitHub Setup → enter your username,
   repo name, and Personal Access Token
5. Click Save & Test Connection
6. You can now edit and Publish Live!

HOW PUBLISH LIVE WORKS:
- You make changes in the admin
- Click Save on each section
- Click Publish Live in the top bar
- Site updates in about 30 seconds

CHANGE YOUR PASSWORD:
The default password is MDadmin2024
After first login, the hash is saved in
your browser. To change it, clear browser
storage and log in with a new password.
