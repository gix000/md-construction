How to get a Personal Access Token
  1. Go to github.com → click your profile photo → Settings
  2. Scroll down → Developer settings
  3. Click Personal access tokens → Tokens (classic)
  4. Click Generate new token (classic)
  5. Give it a name, set expiry, check repo scope
  6. Copy the token and paste it above

Your token is saved in this browser only — it never leaves your device.
