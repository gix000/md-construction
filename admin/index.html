How to get a Personal Access Token
  1. Go to github.com → your profile photo → Settings
  2. Scroll to the bottom → Developer settings
  3. Personal access tokens → Tokens (classic)
  4. Generate new token (classic)
  5. Set a name, expiry, and tick the repo checkbox
  6. Copy and paste the token above

⚠️ Token is saved in your browser only — never sent anywhere except GitHub.
